# 다 비치 (testall)

> 내 오늘 안으로 다 비치

GitHub에서 작업한 페이지들을 **미리보기 + 링크** 카드로 한 화면에 모은 PWA입니다.
폰 홈 화면에 앱처럼 설치해 두고 바로 찾아 들어갈 수 있습니다.

- 주소: https://kwonyujin119.github.io/testall/
- 카드 목록: `data.js` (제목·설명·주소·태그). 새 리포는 GitHub API에서 자동으로 추가됩니다.
- 미리보기: GitHub Pages가 있는 리포는 실제 화면을 축소해 보여 주고, 없는 리포는 GitHub 소셜 카드 이미지를 보여 줍니다.
- 설치: 안드로이드·PC 크롬은 상단 **앱 설치** 버튼, 아이폰은 Safari 공유 → **홈 화면에 추가**.

## 입장 코드와 관리자

- 처음 열면 입장 코드 화면이 나옵니다. 사용자 코드로 들어가면 공개 카드만 보입니다.
- 관리자 코드로 들어가거나, 들어간 뒤 🔑 버튼에서 관리자 코드를 넣으면 관리자 모드가 됩니다. 상단에 금색 **🛡 관리자** 표시가 붙습니다.
- 관리자는 카드마다 공개 스위치로 공개·비공개를 바꾸고 **저장**합니다. 저장하면 `visibility.json`이 GitHub API로 커밋되고, 1~2분 뒤 배포가 끝나면 모든 사람에게 반영됩니다.
- 저장에는 `testall` 리포의 Contents 쓰기 권한이 있는 Fine-grained 토큰이 관리자 기기마다 한 번 필요합니다. 토큰은 그 기기 브라우저에만 보관됩니다.
- 코드는 페이지에 SHA-256 해시로만 들어 있습니다. 다만 정적 사이트라 서버 검사가 없고 리포가 공개라서, 이 잠금은 가벼운 가림막입니다. 비공개 카드도 GitHub 리포 자체는 공개 상태입니다.
- 코드를 바꾸려면 `index.html`의 `H_USER`, `H_ADMIN` 값을 `sha256("testall:" + 새코드)` 결과로 바꿉니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면·동작 전부 (CSS·JS 포함) |
| `data.js` | 카드 데이터 |
| `visibility.json` | 비공개 카드 목록 (관리자 화면에서 저장) |
| `manifest.webmanifest`, `sw.js`, `icons/` | PWA 설치·오프라인 |
| `.github/workflows/pages.yml` | main 푸시 시 GitHub Pages 배포 |
